## 1. 一句话问题

> 一个网约车司机，在一天之内，**什么时候该停下挣钱、去把电补上？**

把它拆成决策维度：

| 维度 | 问题 | 本模型 |
|---|---|---|
| **何时** | 哪一个 15 分钟去补能 | ✅ 核心决策 |
| **补多少** | 充到多少停 | ✅ 由"充多久"决定 |
| **去不去** | 这一格是接单还是补能 | ✅ 二元动作 |
| **去哪** | 在城市里选哪一个站 | ❌ 主动放弃，见 §8 |

**一句话的准确版本**：

> 给定一个随时间变化的订单到达过程、一处随时变化且不透明的充电价格、以及一个**需要等待**的充电设施，一个以日净收入最大化为目标的司机，应当在哪个时刻下线补能？

注意最后三个字的重量：**需要等待**。这是本版与 v2 最大的差别——v2 假设到了就能充，v3 把"等待"放回模型。

## 2. 决策者画像

| 项 | 取值 | 依据 |
|---|---|---|
| 单位 | **一个司机**，不是车队 | v2 已确立，也是与文献的差异点 |
| 目标 | **日净收入最大化** | 收益最大化，不是成本最小化 |
| 班次 | 约 10–12 小时，96 个 15 分钟格 | 与需求曲线对齐 |
| 车辆 | 主流营运纯电轿车，57.6 kWh / 90 kW 峰值 | 【硬】秦PLUS EV 510 km 版 |
| 充电设施 | 不拥有，**价格接受者** | 司机是 price taker |
| 信息 | **不完备**：不知道各站实时占用与实时价格 | 【中】司机手机装 3–5 个充电 App |

**最后一条决定了问题的性质**。如果价格公开且确定，这就是一个排程问题；因为价格不透明，它更接近一个**在不确定环境下的序贯决策**问题。这是本模型用 DP 而不是线性规划的原因之一。

## 3. 成本结构：五因子的重排

司机的一次补能，真正付出的是下面这个式子：

```
单次补能总成本 = 电费 × 电量
               + (寻路时间 + 排队时间) × 时间价值(t)
               + φ(t) × 插枪充电时间 × 时间价值(t)
```

**关键的结构判断**：你列的第五项"占用接单时间"**不是并列的第五项，而是前四项时间的计价单位**。少接一单损失多少钱，取决于**在哪个时刻少接**。所以它们的正确位置是：

| 你的编号 | 因子 | 在式子里的位置 | 性质 |
|---|---|---|---|
| ⑤ | 寻路 | 时间项 1 | 满额，可预测 |
| ② | 排队 | 时间项 2 | **满额，不可预测，不可复用** |
| ③ | 插枪充电 | 时间项 3 | **打折 φ**，可与休息重叠 |
| ④ | 电费 | 价格项 | 金额最大 |
| ① | 占用接单时间 | **乘数 `时间价值(t)`** | 不是独立项 |

这个重排带来三个直接后果：

1. **模型里唯一需要建模的不确定性，只有排队。** 其余全是确定性的物理或价格。
2. **"充电 30 分钟"和"排队 60 分钟"在痛感上根本不是一回事**——前者可以和午饭重叠，后者必须守着。§4 会给出量化。
3. **时间项之间可加，但计价乘数分时段**——所以"在谷段排队"和"在午间排队"，代价完全不同。

## 4. 逐因子：机制、参数、证据强度

### 4.1 机会成本 `v(t)` ——它是乘数

**定义**：司机在 `t` 时刻如果去接单，能拿到的**净**收入（元/小时）。

**参数**

| 项 | 值 | 强度 |
|---|---|---|
| 单位时间毛流水 | 一线 35–50 元/h，二三线 25–40 元/h | 【推断】行业口径，非检索所得 |
| 平台抽成 | 20–30% | 【中】 |
| **净机会成本** | **25–35 元/h** | 【推断】 |
| 实证支付意愿（WTP） | **69.37 元/h** | 【硬】*Transp. Letters* 2026 |

**必须分清的两个数**：`25–35` 是**机会成本**（模型该用的），`69.37` 是**支付意愿**（含心理溢价，**不能**直接当机会成本）。上一轮把 69.37 代入算临界点是不严谨的；本版把它降级为"上界扫描"。

**分时形状**：`v(t)` 由订单分布决定，不是常数。这正是 v2 的核心机制，保留。

### 4.2 排队 `q(t)` ——唯一的不确定性

**机制**：到达时刻的桩位供需比决定等待；而每辆车占用桩多久（充电慢 → 周转慢 → 队更长）又反过来放大等待。

**影响因子**

| 因子 | 作用 | 数据 |
|---|---|---|
| 到达时刻的需求密度 ρ(t) | 直接决定 | 【缺失】只有平均 4.5% |
| 有效桩数（名义 × 可用率） | 分母 | 【缺失】只有个案（某场站 10 桩仅 1 桩可用） |
| 油车占位 | 分母 | 【缺失】 |
| 充电时长分布 | 决定周转 | 【硬】30 分钟量级 |
| 排队规则（FCFS/预约） | 结构 | 【缺失】 |

**这是全链条最大的空洞**，必须诚实写进论文：我们把 `q(t)` 当作**外生函数**并扫描其水平，而不是从数据估计。§8 会说明为什么不做内生均衡。

**两个必须说清的性质**：

- **不可预测** → 司机无法事前规划，只能按经验出发
- **不可复用** → 排队时既不能接单，也不能休息

第二条是 §5 全部结论的来源。

### 4.3 插枪充电 `T_charge` ——最确定、最不痛

**机制**：物理曲线，确定性。CC–CV 特性使 80% 之后功率骤降。

**推导**：57.6 kWh 电池，30% → 80% = **28.8 kWh 入库**，按 92% 效率 = **约 31 kWh 从电网取电**，耗时 **约 30 分钟**。【硬】

**关键折扣因子 `φ(t)`**：插枪时间可以和休息重叠。中午充电时司机本来就要吃饭，边际时间成本接近 0；深夜充电时本来就要收工，也接近 0。
- 基准 `φ = 0.3`（午间），扫描 0–1
- `φ` **不影响"在哪个时段充"的比较**（因为两边的 `T_charge` 相同，互相抵消），**只影响"要不要充"的判断**。这一点在 §5 会再出现。

### 4.4 电费 `p(t)·E` ——金额最大，司机影响力最小

**结构**：终端价 = 电费 + 服务费，两部分**都可以分时**，且来源不同（电网 / 运营商）。

| 项 | 2026 现状 | 强度 |
|---|---|---|
| 电费分时 | **2026-03-01 起对市场参与者作废**（发改能源规〔2025〕1656号），9 省落地、扩至 10 省以上 | 【硬】 |
| 服务费 | 城市 0.5–1.0 元/度，高速 1.5–2；**高峰已涨到 0.9–1.2** | 【软】 |
| 电费:服务费 | 约 61:39（**仅 18 次实测**） | 【软】 |
| 终端综合价 | 1.3–2.0 元/度 | 【中】 |

**基准数值（本版统一口径）**：

| 时段 | 电费 | 服务费 | 综合 | 30 度电 |
|---|---|---|---|---|
| 谷段（正午光伏洼地） | 0.25 | 0.50 | **0.75** | **22.5 元** |
| 峰段（晚高峰） | 1.40 | 1.20 | **2.60** | **78.0 元** |
| **价差** | | | **1.85 元/度** | **55.5 元** |

**上轮的错误已撤回**："峰谷价差收窄 9.4%"是**电费口径**；若服务费在高峰上浮更多，综合价差反而**扩大**。见 §5 的量化。

### 4.5 寻路 `r` ——金额小，但它是唯一"由选择产生"的时间

城市内 10–20 分钟（3–5 km）。可预测、可优化，且**和价格负相关**（便宜的站往往远）。

**这是本模型完全没建模的一项**，也是"选址"痛点的载体。我们把它当**常数**处理（基准 15 分钟），扫描 0–30 分钟。主动放弃空间维度，理由见 §8。

## 5. 量级检验：临界排队时长

在做任何算法之前，先确认这个问题**有内容**——即"排队"真的能翻转结论。

### 5.1 简化版（时间价值视为常数）

把两边都算上：谷段排队 `T` 小时，峰段不排队。寻路和插枪时间两边相同，**互相抵消**。

> 谷段 − 峰段 = −55.5 + `v`·`T`
>
> 令其为零：**`T* = 55.5 / v`**

| 时间价值 `v` | 临界排队 `T*` |
|---|---|
| 25 元/h（乐观机会成本） | **2.2 h** |
| 30 元/h（基准） | **1.85 h** |
| 35 元/h（保守机会成本） | **1.60 h** |
| 69.37 元/h（WTP 上界） | **0.80 h** |

**读法**：只要排队短于这个时长，去谷段仍然划算。现实中高峰排队 1–4 小时【软】，所以**结论落在"部分时段翻转"的区域**——这正是模型值得做的地方。

### 5.2 服务费是否分时，直接改变 `T*`

| 服务费设定 | 谷段综合 | 峰段综合 | 价差 | `T*`（v=30） |
|---|---|---|---|---|
| **分时**（0.5 / 1.2） | 0.75 | 2.60 | 55.5 元 | **1.85 h** |
| **平价**（都 0.7） | 0.95 | 2.10 | 34.5 元 | **1.15 h** |

> **反直觉结论：分时服务费不是"削弱"电价套利，而是"放大"它。** 把价差从 34.5 元拉到 55.5 元（+61%），相当于把司机愿意排的队从 1.15 小时延长到 1.85 小时。

这条如果成立，是一个可以写进论文的独立发现——**运营商的定价策略，通过服务费的时段结构，实际上在鼓励司机扎堆**。

### 5.3 但这个公式还不够

`T* = 价差 / v` 假设 `v` 是常数。真实模型里 `v` 是分时的，而**排队损失的时段恰好是谷段本身**：

- 若谷段在**深夜**：那个时段订单接近零，排队的机会成本≈0 → 几乎怎么排都值
- 若谷段在**正午**（2026 市场化后的新常态）：那个时段订单中等，排队很贵 → 临界时长骤降

> **所以真正的问题不是"排队多久"，而是"电价洼地和订单洼地重合到什么程度"。**

这就是 §7 的 DP 要算的东西：它不需要这个闭式公式，它会自动把"损失的是哪几格"折算进去。

## 6. 四个背景

### 6.1 续航：物理上已经过剩，行为上仍然绑定

| 口径 | 日均里程 | 每日需电量 | 占电池比例 |
|---|---|---|---|
| 广东官方（活跃车，≥10 单/日） | **135 km** | ≈20 kWh | **0.39** |
| 平台口径 | **280 km** | ≈42 kWh | **0.81** |
| 行业报告 | **328 km** | ≈49 kWh | **0.95** |

【硬】续航：CLTC 460–610 km，城市实际 350–420 km，冬季再打七折。

**反直觉之处**：即使按最大的 328 km、按 400 km 实际续航算，也**只需要 1.2 天充一次**；按 135 km 算，**三天才需要充一次**。

**但司机每天充 1–2 次。** 所以约束不是物理的，是行为的：
1. 心理安全边际——没人敢跑到 10% 再找桩
2. **接单自由度**——电量低不敢接远单，等于放弃收入
3. 时间窗口——补能必须塞进午休/收工

**对模型的意义**：这把 reserve floor `s^min` 从"随手设的参数"变成了**有真实行为含义的约束**。也解释了 v2 的 S1 为什么"电池越大增益越掉"——不是大电池不用充，是**大电池不需要精确安排何时充**。

**口径必须选一个**（三套差 2.4 倍）。默认取 **280 km（平台口径）** 作基准，135 / 328 作双情景。理由：平台口径最贴近"司机实际跑出来的单"，且落在另两者之间。**必须在论文里写明这是选择，不是事实。**

### 6.2 充电速度：正在从物理上抹掉"充电时间"这一项

【硬】公共枪平均 **46.53 kW**；250 kW+ 仅占 **3.3%**；主流车峰值 90 kW。

**趋势**：800V + 4C 已进 15 分钟区间（10→80%），2026 年正向营运车型下沉。

**双向影响**：
- **对我们不利**：充电时间趋零，"何时充"的排程价值下降（v2 的 S3 方向：7 kW 增益 +262 → 200 kW 增益 +158）
- **对我们有利**：桩快了，桩的周转也快了，**排队会自然缩短**

必须诚实写进去：**技术正在同时削弱这五项里的两项。**

### 6.3 订单随时间分布：机会成本曲线的来源

双峰形态（典型工作日）：

| 时段 | 相对强度 | 司机通常做什么 |
|---|---|---|
| 07–09 早高峰 | 最高 | 全在路上 |
| 09–11 平峰 | 中 | 可休息 |
| **11–14 午间** | 中低 | **吃饭 + 补能** |
| 17–19 晚高峰 | 最高 | 全在路上 |
| 21–23 收工前 | 中低 | **第二次补能窗口** |
| 00–05 深夜 | ≈0 | 收工 |

【硬】v2 基于 NYC TLC 274 万笔真实订单估计，**峰值/谷值 = 18.5×**。

**两个要点**：
1. 这条曲线决定了 `v(t)` 的形状，是模型的核心输入。
2. **错配才是机会**：司机的两个天然休息窗口（午间、收工前），与电价洼地（市场化后是正午 + 夜间）**部分重合、部分不重合**。重合处会拥堵，不重合处才有机可图。

### 6.4 城市地图：我们主动放弃的维度

**现实**：一二线核心区每平方公里 5–20 个公共站，到最近站 0.5–2 km。但——

> **"最近的站"、"有空桩的站"、"便宜的站"，经常不是同一个。**

于是选址是三目标冲突：**距离 × 排队 × 价格**，而司机信息不完备（3–5 个 App 就是在手动解决这个问题）。

**为什么不做**：空间维度会让状态从 `(t, s)` 变成 `(t, s, 位置)`，状态空间爆炸；而我们只有单点数据，强行做等于"编一张地图"。

**正确做法**：写成明确边界——"本文的结论是关于**时机**的，不是关于**选址**的；选址需要站点级数据，是后续工作。"

## 7. 形式化：状态、动作、转移、目标

### 7.1 记号

```
T = 96 个时段，Δt = 15 min = 0.25 h
状态  s_t ∈ S = {0.15, 0.16, …, 1.00}      （86 点，1% 网格）
动作  a_t ∈ { DRIVE, CHARGE }
```

`IDLE` 省去：只要 `λ_t > 0`，待机被接单弱支配（少赚且不少耗电）。v2 已论证。

### 7.2 转移：把"排队"变成"时间跳跃"

**这是本版最重要的建模改变。**

设 `q(t)` = 在 `t` 时刻去充要排的队（换算成格数），`r` = 寻路格数（常数）。则补能一次要离开路面

```
D(t) = r + q(t) + 1        （寻路 + 排队 + 插枪）
```

于是：

| 动作 | 下一决策时刻 | 电量 | 立即收益 |
|---|---|---|---|
| **DRIVE** | `t + 1` | `s − m_t·e_t/Q` | `+ m_t·f_t` |
| **CHARGE** | `t + D(t)` | `s + P·τ(s)·η·Δt/Q` | `− p(t)·P·Δt` |

约束：`s_t ≥ s^min` 恒成立；跌破判**不可行**（不能 clamp，这是 v2 最贵的 bug）。

**为什么这个写法好**：

1. **机会成本不用再设参数**。充电造成的是 `D(t)` 个格子不接单，损失自动由 DP 按**那几格各自的 `v`** 折算——深夜排队几乎免费，晚高峰排队极贵，模型自己知道。v2 需要用 `m_t·f_t` 显式表示机会成本，本版让它自然涌现。
2. **状态空间不变**，仍是 `(t, s)`，因为 `q(t)` 只依赖 `t`（外生），不依赖 `s`。8,256 个状态，毫秒级可解。
3. **直接对上你列的五项**：寻路 = `r` 格，排队 = `q(t)` 格，充电 = 1 格，电费 = `p(t)·P·Δt`，占用接单时间 = 被跳过的 `D(t)` 格的机会成本。

### 7.3 目标

```
max_π  E[ Σ_t  r_t(a_t) ]
```

subject to 7.2 的转移与 `s_t ≥ s^min`。

**注意**：目标里**不出现**"时间价值 `v`"这个参数。它是内生的。这修掉了 v2 的一个软肋——v2 的隐含 VOT 被算成 \$53/h，高于文献实测的 \$15–28/h，只能靠重标定辩护；本版不需要辩护，因为它不设这个参数。

### 7.4 递推

```
V(t, s) = max {
    DRIVE:   m_t·f_t + V( t+1,       s − m_t·e_t/Q ),
    CHARGE:  −p(t)·P·Δt + V( t+D(t), s + P·τ(s)·η·Δt/Q )
}
```

边界：`V(T, s) = 0`（单日）；或接跨日价值函数 `W(s)` 求不动点（v2 §4.7 的循环版本，可保留）。

`CHARGE` 若 `t + D(t) > T` 或途中跌破 `s^min`，判不可行。

## 8. 模型边界：我们主动放弃什么

**这一节的写法决定了评审是"你没想到"还是"你有意识地收窄"。**

| 放弃项 | 为什么 | 怎么写 |
|---|---|---|
| **空间选址** | 状态爆炸 + 无站点级数据 | "本文的结论关于时机，不关于选址" |
| **多司机均衡** | `q(t)` 若内生，需要不动点或博弈，3 天做不完 | "我们把排队设为外生并扫描，而非求均衡" |
| **换电替代** | 离散选择，破坏状态空间连续性 | "换电作为上界参照，不作机制" |
| **坏桩 / 油车占位** | 治理问题，优化无解 | "列入 limitation，它解释了为什么平均利用率低却有排队" |
| **充电曲线细节** | 15 分钟网格分辨不出 CC–CV 拐点（v2 A3） | 保留 taper，但标注"在本粒度下不可分辨" |
| **平台派单策略** | 视为外生需求过程 | 与 v2 一致 |

**特别提醒（必须写）**：平均利用率 **4.5%** 与"排队 1–4 小时"并存，最朴素的解释是**有效桩少**（坏桩、占位），而不是需求集中在几十倍。拥堵大概率是

> **有效桩少（分母变小）× 需求时间聚集（分子扎堆）**

两者相乘。**其中一半是治理问题，我们的模型解决不了那一半。** 不写这句，会被问穿。
