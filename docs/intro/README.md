## 1. 背景

### 1.1 电动化正在把成本从"加油"变成"排队"

网约车平台正在大规模换电动车。这不是为了环保，是因为运营成本——但这笔账有个被普遍低估的部分。

电动车充电需要的时间远长于加油：一台主流续航的电动车用 50 kW 直流快充从低电量充到 80%，需要约 **50 分钟**；而燃油车加油只要几分钟。

对普通车主这只是不便。对网约车司机，这是**直接的收入损失**——因为车停在那里不接单，就没有任何现金流。文献 [1] 在卢森堡的动态网约车案例中测得：优化充电调度可减少 **74.9%** 的充电等待时间与 **38.6%** 的充电时长。

于是网约车电动车充电管理成了一个真正的运营问题，而不只是环保议题。

### 1.2 但"错峰充电"这套答案在这里不够用

一个直觉的答案是：看分时电价表，在最便宜的时段充电。

这个答案在**车队/场站**场景（货车、公交、网约车队集中充电）里大致成立，因为那里的约束是变压器容量和需量电费。

但对**单个司机**，这个答案是错的。原因是司机同时是两个角色：

- 他是**电力的消费者**，想用便宜的电
- 他是**赚钱的工具**，下线就没有收入

而**日内需求不是平的**。基于 NYC TLC 280 万笔真实订单，全市的订单率在 03:00 到 18:00 之间摆动 **18.5 倍**。

> 这意味着"谷段电价便宜"和"谷段没什么单子可接"是**同时**成立的。

于是：挪到更晚的平段去充，多跑两小时赚到的钱，可能**超过**那 \$0.08/kWh 的峰谷价差。**最便宜的电，不是最后该买的电。**

### 1.3 我们要问的问题

> **一个电动网约车司机，应当在一天中的什么时候充电，才能使净收益最大？**

这个问题是自拟的（不直接落在课程推荐的三个方向内），并且刻意聚焦在**单个司机**而非车队层面——理由见 `docs/related-works/`。

## 2. 研究问题的精确形式

| 项 | 内容 |
|---|---|
| **决策** | 每个 15 分钟时段：跑车 / 充电 / 待机 |
| **目标** | 最大化 日净收益 = 车费收入 − 电费 |
| **不确定性** | 订单随机到达（泊松） |
| **关键结构** | 司机的产出受**物理时间上限**卡死，因此充电有真实的日内机会成本 |

**为什么这是优化问题而不是描述性研究**：因为存在**可行与不可行之分**。一个照着电价表充电的策略，在我们的实验中 **600 个工作日里有 89% 撑不到收车**——它不是赚得少，是**开不出车**。这不是"可以优化"，这是"不优化就不可行"。

## 3. 我们的贡献

1. **一个由真实数据驱动的单司机模型**：需求、车费、能耗全部估计自 NYC TLC 280 万笔真实订单，而非合成假设
2. **用精确 DP/MDP 而非 MILP**：车队规模文献必须用序贯 MILP 或启发式；缩小到单司机后，状态空间只有 8,256，可闭式精确求解
3. **一条反直觉的稳健结论**：最优充电时刻**不在谷段**，且该结论在机会成本变动 3.4 倍后依然成立
4. **一个负面结果**：峰谷价差几乎不影响优化价值——**机会成本才是决定因素，电价退居次要**。这解释了为什么网约车补能问题不能照搬纯 EV 错峰充电结论
5. **一次时间价值校准**：我们模型的隐含 VOT（\$53/h 均值）高于文献实测（\$15–28/h），但我们用文献区间重标定后检验了主结论的稳健性

## 4. 论文对应的引言骨架

写英文论文时，本文档可压缩为：

1. **Background**：网约车电动化 → 充电时长 = 收入损失 → 车队规模文献已解决排队与分配
2. **Gap**：但车队方法假设司机是"被调度的资源"；**单个司机自己决定何时充电**时，机会成本由日内需求形状决定，而车队模型通常把需求当作给定
3. **Research question**：一个司机何时充电净收益最大？
4. **Why optimization**：存在可行/不可行之分，不是"锦上添花"
5. **Contribution**：上面 5 条
